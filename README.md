# Simulado TOFAS - 8º ano

## Publicar no GitHub Pages
1. Envie todos os arquivos desta pasta para a raiz de um repositório.
2. Acesse **Settings > Pages**.
3. Selecione **Deploy from a branch**, branch `main`, pasta `/ (root)` e salve.

## Conectar o Google Planilhas
1. Crie uma planilha e abra **Extensões > Apps Script**.
2. Cole o conteúdo de `google-apps-script.gs`.
3. Selecione **Implantar > Nova implantação > Aplicativo da Web**.
4. Execute como você e permita acesso a qualquer pessoa.
5. Copie a URL terminada em `/exec` e cole em `config.js`.
6. Envie o `config.js` atualizado ao GitHub.
